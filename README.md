# EduHelper Platform
Монорепозиторий образовательной платформы.

## Структура

- `packages/shared` - общие UI компоненты и утилиты
- `packages/client` - React-приложение
- `packages/server` - Express бэкенд

## Запуск

# Установка зависимостей (в корне)
npm install

# Запуск в режиме разработки
npm run dev

# Запуск только клиента
npm run dev:client

# Запуск только сервера
npm run dev:server

# Технологии
- React 18, TypeScript, Vite
- Node.js, Express
- Jest для тестирования
- ESLint (2 пробела, без ;)
