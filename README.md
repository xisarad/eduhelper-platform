# EduHelper - Образовательная платформа

## Описание проекта
Платформа для управления обучением, отслеживания прогресса и проверки домашних заданий.

## Структура репозитория
- `architecture.md` - архитектурные требования
- `mvp.md` - функциональные требования MVP

## Технологии
- React 18 + TypeScript
- Node.js + Express
- PostgreSQL + Prisma
- Material UI
