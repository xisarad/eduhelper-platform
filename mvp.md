# MVP курсовой работы "EduHelper"

## Use Case: Отправка домашнего задания на проверку

### Акторы
- **Студент** - пользователь, который проходит курс и выполняет задания
- **Преподаватель** - пользователь, который проверяет задания

### Предусловия
1. Студент авторизован в системе
2. Студент зачислен на курс
3. У курса есть активное домашнее задание

### Основной сценарий

#### 1. Просмотр домашнего задания
1. Студент заходит на страницу курса
2. Нажимает на раздел "Домашнее задание"
3. Система отображает:
   - Текст задания
   - Дедлайн сдачи
   - Примеры выполнения
   - Критерии оценки

#### 2. Отправка решения
1. Студент нажимает кнопку "Отправить решение"
2. Система открывает форму отправки
3. Студент:
   - Вводит текстовое описание решения
   - Прикрепляет файлы (до 5 файлов, каждый до 10MB)
   - Добавляет комментарий для преподавателя (опционально)
4. Студент нажимает "Отправить на проверку"
5. Система валидирует:
   - Заполнено ли описание
   - Проверяет типы файлов (.pdf, .doc, .zip, .png, .jpg)
   - Проверяет размер файлов
6. При успешной валидации:
   - Система сохраняет решение
   - Статус задания меняется на "На проверке"
   - Отправляется уведомление преподавателю
   - Показывается сообщение об успехе

#### 3. Проверка преподавателем
1. Преподаватель заходит в раздел "Проверка работ"
2. Видит список ожидающих проверки заданий
3. Открывает работу студента
4. Просматривает решение и прикреплённые файлы
5. Выставляет оценку (0-100) и пишет комментарий
6. Нажимает "Одобрить" или "Отправить на доработку"
7. Система:
   - Обновляет статус задания
   - Отправляет уведомление студенту
   - Сохраняет оценку в истории

#### 4. Получение результата
1. Студент получает уведомление о проверке
2. Заходит в раздел "Домашние задания"
3. Видит статус и комментарий преподавателя
4. Если задание отправлено на доработку:
   - Студент может исправить ошибки
   - Отправить повторно
5. Если задание одобрено:
   - Студент видит полученные баллы
   - Баллы добавляются в общий прогресс курса

### Альтернативные сценарии

#### A1. Пропущен дедлайн
1. Система блокирует отправку после дедлайна
2. Отображается сообщение "Срок сдачи истёк"
3. Требуется согласование с преподавателем

#### A2. Невалидные файлы
1. Система отклоняет файлы с неподдерживаемым форматом
2. Показывает сообщение об ошибке
3. Предлагает загрузить корректные файлы

#### A3. Ошибка сети при отправке
1. Система сохраняет решение локально
2. Показывает статус "Не отправлено"
3. Предлагает повторить отправку

### Постусловия
- Решение студента сохранено в БД
- Статус задания обновлён
- Уведомления отправлены
- Прогресс курса пересчитан

## MVP Scope (обязательная реализация)

✅ **Функциональность 1-й итерации (обязательно):**
- [ ] Регистрация/вход пользователей
- [ ] Просмотр списка курсов
- [ ] Отправка домашнего задания
- [ ] Просмотр статуса проверки
- [ ] Базовый личный кабинет

✅ **Функциональность 2-й итерации (приоритетно):**
- [ ] Проверка заданий преподавателем
- [ ] Уведомления (email/in-app)
- [ ] Прогресс по курсу
- [ ] Загрузка учебных материалов

✅ **Функциональность 3-й итерации (план):**
- [ ] Чат с преподавателем
- [ ] Групповые проекты
- [ ] Сертификаты об окончании

## Метрики успеха MVP
- Время отправки задания < 2 минут
- Загрузка страницы < 3 секунд
- 95% успешных отправок
- Покрытие тестами > 80%
